# 🌐 AutiSphere: VR/MR Rehabilitation Platform for Autism

## 📌 Introduction
AutiSphere is a Virtual Reality (VR) and Mixed Reality (MR) rehabilitation platform designed to support individuals with autism.  
It provides **immersive daily living skill training** (e.g., handwashing) and **emotional recognition exercises**, helping users transition from virtual training to real-world rehabilitation.

---

## 🎯 Objectives
- Support autism rehabilitation through **safe and structured immersive environments**.  
- Provide **dual VR/MR modes**:  
  - VR Mode → fully immersive for controlled learning.  
  - MR Mode → bridges training to real-world scenarios.  
- Enhance emotional skills with **expression recognition exercises**.  
- Encourage independent living skills in a supportive, repeatable environment.

---

## 📖 Related Literature
Research in autism rehabilitation highlights:  
- VR as an effective tool for **skill acquisition**.  
- MR as a bridge for **real-world application**.  
- Emotion recognition training improves **social interaction outcomes**.  

AutiSphere builds on these findings by integrating **immersive daily living tasks and emotional recognition** into a unified platform.

---

## 🛠️ Methodology
1. **Platform**: Built in **Unity** with XR SDK.  
2. **Tasks**: Handwashing training with step-by-step guidance (faucet, soap, scrubbing, towel drying).  
3. **Modes**:  
   - VR Mode: Full immersion training.  
   - MR Mode: Blends training with the physical environment.  
4. **Emotion Recognition**: Integration of expression recognition exercises.  
5. **Evaluation**: User can select mode depending on autism spectrum needs.

---

## 📊 Results
- Developed a **functional VR/MR prototype**.  
- Users can **choose immersive VR or MR mode**.  
- Handwashing and emotion-recognition tasks successfully demonstrated.  
- Provides both **learning and real-life rehabilitation pathways**.

---

## 🔍 Analysis
- VR improves **engagement and learning** in autism rehabilitation.  
- MR supports **generalization of learned skills** to the real world.  
- The prototype validates the **feasibility** of combining VR and MR for rehabilitation.

---

## ✅ Conclusion & Future Work
AutiSphere shows promising potential for autism rehabilitation:  
- Safe, structured, and repeatable learning environments.  
- Dual VR/MR modes tailored to user needs.  

**Future Work:**  
- Expand rehabilitation tasks (cooking, dressing, etc.).  
- Enhance emotion recognition accuracy.  
- Integrate **AI with Computer Vision** to automatically detect whether users perform tasks correctly (e.g., handwashing steps).  
- Conduct broader clinical validation studies.
